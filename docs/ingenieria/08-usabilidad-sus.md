# Protocolo de usabilidad con SUS

## Participantes y preparación

Reclutar de 5 a 10 médicos o residentes con experiencia o formación en lectura de ecografía mamaria. Registrar por código el perfil y la familiaridad con visores. La muestra sirve para identificar dificultades operativas y obtener una medida descriptiva. Emplear la misma revisión de EcoAudit, máquina, navegador, hoja de tareas, cuentas ficticias e imágenes autorizadas para cada participante. Preparar al menos un resultado indeterminado o fuera de dominio para la tarea de interpretación.

El moderador presenta el propósito, obtiene consentimiento y entrega las consignas sin revelar los pasos de solución. El observador mide tiempo desde la lectura de la consigna hasta su conclusión o el límite común de cinco minutos por tarea. Si hay ayuda, registrar momento y motivo. Las tareas se aplican en orden y, si una falla impide continuar, el moderador restablece un punto inicial equivalente y documenta la intervención.

## Tareas guiadas por consigna

| Tarea | Consigna | Evidencia de éxito |
| --- | --- | --- |
| T1 | Inicie sesión y cree un caso con el seudónimo entregado. | Nuevo caso visible con el seudónimo correcto. |
| T2 | Cargue la ecografía asignada e indique qué avisos de calidad aparecen. | Imagen visible e identificación de las banderas preparadas. |
| T3 | Delimite la región indicada. Si hay localizador disponible, revise su propuesta y ajústela. | ROI revisado y análisis solicitado con la selección final. |
| T4 | Encuentre la salida asignada, active o desactive el mapa y explique qué significa una abstención. | Localiza resultado y CAM. Explica el límite experimental sin convertirlo en diagnóstico. |
| T5 | Descargue el informe y señale la versión usada. | PDF abierto y versión identificada. |
| T6 · I4 | Registre de forma independiente la categoría BI-RADS de una imagen de prueba en el recorrido ciego. | Lectura propia guardada sin consultar resultado algorítmico ni la lectura ajena. |

Antes de T6, verifique que el recorrido ciego está disponible y aislado. Use una imagen distinta de la mostrada con resultado en T4. Si T6 queda bloqueada en la revisión ensayada, documente el motivo y aplique T1–T5 a todos para mantener la comparabilidad. Para la tasa de tareas, el denominador son las consignas disponibles y asignadas. Los abandonos, ayudas y vencimientos de tareas asignadas no cuentan como éxitos sin ayuda.

## Consentimiento informado

Se me invita a participar voluntariamente en una evaluación de la interfaz de EcoAudit. La sesión dura aproximadamente 30–45 minutos e incluye tareas con datos ficticios o autorizados y un cuestionario. Se evaluará la interfaz y se registrarán tiempos, observaciones y respuestas con un código. Puedo omitir preguntas y retirarme sin consecuencia. Los resultados se comunicarán de forma agrupada. Antes de firmar se me informará quién custodia los registros, el plazo de conservación y el contacto para ejercer mis derechos o plantear dudas. Los resultados del prototipo carecen de uso asistencial. La grabación, si se propone, requiere consentimiento específico.

## Cuestionario SUS

Aplicar inmediatamente después de las tareas, de forma individual y antes de comentar los errores. Marcar una respuesta por ítem. Escala: **1** totalmente en desacuerdo, **2** en desacuerdo, **3** ni de acuerdo ni en desacuerdo, **4** de acuerdo, **5** totalmente de acuerdo. Traducción operativa de los diez ítems de Brooke para el piloto.

| N.º | Afirmación | Respuesta (1–5) |
| --- | --- | --- |
| 1 | Creo que me gustaría utilizar este sistema con frecuencia. | |
| 2 | Encontré el sistema innecesariamente complejo. | |
| 3 | Pensé que el sistema era fácil de usar. | |
| 4 | Creo que necesitaría el apoyo de una persona con conocimientos técnicos para usar este sistema. | |
| 5 | Encontré que las distintas funciones del sistema estaban bien integradas. | |
| 6 | Pensé que había demasiadas inconsistencias en el sistema. | |
| 7 | Imagino que la mayoría de las personas aprendería a usar este sistema rápidamente. | |
| 8 | Encontré el sistema muy engorroso de usar. | |
| 9 | Me sentí seguro al usar el sistema. | |
| 10 | Necesité aprender muchas cosas antes de poder usar este sistema. | |

Para ítems impares, aporte = respuesta − 1. Para pares, aporte = 5 − respuesta. Sumar los diez aportes y multiplicar por 2,5. El puntaje va de 0 a 100 y se interpreta como escala, sin signo de porcentaje. Si falta una respuesta, conservar el cuestionario como incompleto y excluirlo de la media, informando el número. Reportar n, media, mediana, rango y observaciones agrupadas. El umbral interno propuesto es media ≥ 70 junto con ≥ 80 % de tareas completas sin ayuda y cero confusiones de la abstención con un diagnóstico.
